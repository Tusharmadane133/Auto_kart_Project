# Blog Content Formatting Guide

This guide explains how to format your blog content so it displays properly on the user-facing site.

## 📝 Supported Formatting

### 1. **Bullet Points**
Use hyphen (-), asterisk (*), or plus (+) at the beginning of lines:

```
- First point
- Second point
- Third point
```

OR

```
* First point
* Second point
* Third point
```

### 2. **Numbered Lists**
Use numbers followed by a dot:

```
1. First step
2. Second step
3. Third step
```

### 3. **Bold Text**
Wrap text in double asterisks:

```
**This text will be bold**
```

### 4. **Italic Text**
Wrap text in single asterisks:

```
*This text will be italic*
```

### 5. **Headers**
Use hash symbols (#) for different header levels:

```
# Main Header (H1)
## Subheader (H2)
### Sub-subheader (H3)
```

### 6. **Links**
Use the format `[text](url)`:

```
[Click here to visit AutoKart](https://autokart.com)
```

### 7. **Code/Inline Text**
Wrap text in backticks:

```
Use `npm install` to install packages
```

### 8. **Line Breaks**
Simply press Enter twice for paragraph breaks, or once for line breaks within paragraphs.

## ⚠️ Important Notes

1. **Consistent Formatting**: Use the same formatting style throughout your content
2. **Clear Structure**: Use headers to organize your content logically
3. **Short Paragraphs**: Keep paragraphs under 4-5 sentences for better readability
4. **Visual Breaks**: Use bullet points and numbered lists to break up long text
5. **Test Preview**: Always preview your content before publishing

## 🔧 Technical Details

The blog system automatically converts:
- Markdown-style formatting to HTML
- Plain text line breaks to proper paragraphs
- Lists to proper HTML `<ul>` and `<ol>` elements
- Text formatting to `<strong>`, `<em>`, and `<code>` tags

This ensures your content looks professional and is properly formatted across all blog pages (index, post, category, and tag pages).
